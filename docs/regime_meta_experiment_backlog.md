## Measurement Workflow
1. Capture raw CLI logs and append ledger rows to `log/backtest.csv` after each run with descriptive labels (`append` command in `src/backtesting/output.py`).
2. Run `src/backtesting/evaluate_logs.py` against each pair (baseline vs variant) to extract Sharpe/Sortino, drawdown, and override counts, exporting to `log/backtest_metrics_regime_meta_rmcalXX.csv`.
3. Feed risk override CSVs into `poetry run python -m src.backtesting.analyze_risk_conflicts` for compliance ratios and issue tagging; stash Markdown summaries alongside CSV outputs for quick inspection.
4. Track calibration deltas with `src/tools/ml_diagnostics.py` for Platt scaling and the new regime weights, ensuring RMS error drops vs. current calibration payload.
